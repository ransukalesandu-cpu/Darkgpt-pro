# Streamlit Chat Application

This is a simple chat application built using Streamlit and various AI models for text generation. It allows users to interact with different AI models to generate responses to their queries.

[Streamlit app](https://darkgpt.streamlit.app/)
[Hugging Face Space](https://huggingface.co/spaces/codewithDark/DarkGPT)

## Features
- Multiple AI model choices
- Chat history
- Dynamic model selection
- Text summarization and analysis

## Installation
```bash
pip install -r requirements.txt
streamlit run app.py
```

Open http://localhost:8501 after starting the app.
